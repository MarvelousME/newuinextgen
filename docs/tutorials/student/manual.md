# Student User Manual

## Overview
Access sessions, progress visibility, and schedule-related information.

## Logging In
Use student credentials from registration; password reset via lost-password.

## Navigation
- Student dashboard
- Session schedule
- Support

## Features
- upcoming/recent sessions
- tutor visibility
- progress-oriented dashboard cards

## Daily Usage
Review upcoming session details and complete assigned learning tasks.

## Troubleshooting
If sessions are missing, contact support/admin for booking assignment validation.

## FAQ
- Q: Can students directly approve payouts?  
  A: No, payout flow is finance/admin controlled.
