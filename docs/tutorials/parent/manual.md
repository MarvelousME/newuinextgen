# Parent User Manual

## Overview
Manage learner profiles, tutor matching, bookings, payments, and reviews.

## Logging In
Use platform login page; reset via WordPress lost password flow if needed.

## Navigation
- Parent dashboard
- Find tutor
- Booking/payment pages
- Support/contact

## Features
- learner management
- tutor discovery + calendar slot selection
- booking and payment tracking
- review submission

## Daily Usage
Check upcoming sessions, update learner needs, confirm bookings, review outcomes.

## Troubleshooting
Use support form if booking/payment data appears inconsistent.

## FAQ
- Q: Can I book unavailable slot?  
  A: No, only public available slots can be requested/booked.
