# Tutor User Manual

## Overview
Apply, onboard, accept matches, manage sessions, and track payouts.

## Logging In
Use tutor account credentials after approval.

## Navigation
- Tutor dashboard
- Match/booking flows
- Profile pages

## Features
- applicant to approved lifecycle
- booking/session status handling
- earnings and pending payout visibility

## Daily Usage
Review schedule, complete sessions, keep profile accurate, monitor payout state.

## Troubleshooting
If approval or booking data is inconsistent, escalate via support/admin.

## FAQ
- Q: Why no Amelia calendar sync?  
  A: Amelia integration requires plugin activation and API key configuration.
