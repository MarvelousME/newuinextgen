# Support User Manual

## Overview
Assist users with registration, matching, booking, and escalation flows.

## Logging In
Use support role account (`ngc_support`) or admin account.

## Navigation
- Matches and bookings screens
- Support intake routes
- Verification/health screens

## Features
- match and booking triage
- tutor application support context
- escalation handling

## Daily Usage
Resolve user issues, escalate unresolved incidents, log outcomes.

## Troubleshooting
Use troubleshooting matrix and audit/workflow logs to isolate failures.

## FAQ
- Q: How to escalate critical incidents?  
  A: Trigger escalation workflow and attach verification/audit evidence.
