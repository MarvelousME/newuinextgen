# Finance User Manual

## Overview
Monitor payout/payment indicators and process tutor payouts.

## Logging In
Use finance role account (`ngc_finance`) or admin account.

## Navigation
- Payouts screen
- Admin analytics views
- Verification/health checks

## Features
- pending payout visibility
- payout execution
- finance metric monitoring

## Daily Usage
Review pending earnings, process payouts, confirm payout audit entries.

## Troubleshooting
If payment/invoice metrics are incomplete, validate WooCommerce runtime status.

## FAQ
- Q: Why are invoice metrics partial?  
  A: WooCommerce runtime is required for full payment/invoice signal chain.
