# NextGen Tutors Plugin

Welcome to the **NextGen Tutors** core plugin. This plugin converts your WordPress installation into a full-fledged tutoring platform, integrating your LMS, bookings, and automated payouts with an advanced "Mission Control" dashboard.

## Installation

1. Upload the `nextgen-tutors` folder to your `/wp-content/plugins/` directory (or upload the `.zip` file via the WordPress admin panel).
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Upon activation, the plugin will automatically create the necessary database tables (`wp_ngt_earnings`, `wp_ngt_payouts`, `wp_ngt_logs`, `wp_ngt_triggers`, `wp_ngt_workflows`).
4. A new **NextGen Tutors** menu will appear in the admin sidebar.

## Required Integrations

The plugin works alongside several other tools to provide a seamless experience. Navigate to **NextGen Tutors > Integrations** to one-click install and activate the following required plugins:
- FluentCRM
- Fluent Forms
- Masterstudy LMS
- Amelia Booking
- AutomatorWP
- WooCommerce
- PayFast
- GamiPress
- Amelia Notifier

## Usage & Documentation

Detailed step-by-step documentation on how to configure triggers, build workflows, and manage payouts is provided within the **tutorial.md** file, which can be downloaded directly from the **Settings** tab within Mission Control.
