Security Test Cases

TC-21: SQL Injection Prevention

Attempt SQL injection in all form fields (Fluent Forms search, contact form, tutor application). Verify all inputs sanitized, no SQL errors in logs.

TC-22: XSS Prevention

Submit script tags in all text fields. Verify output is escaped (esc_html, esc_attr), no script execution in browser.

TC-23: Authentication Bypass

Attempt to access dashboard endpoints without Bearer token. Verify 401 Unauthorized response. Attempt with expired/invalid token. Verify rejection.

TC-24: CSRF Protection

Submit forms without nonce. Verify form rejected. Submit with expired nonce. Verify rejection.

TC-25: Role Escalation

Login as Student, attempt to access Tutor dashboard or Admin pages. Verify access denied (403). Login as Tutor, attempt to access Admin pages. Verify denied.

TC-26: POPIA Consent

Register under-18 student without parent consent checkbox. Verify registration blocked. Verify consent is stored in order meta and user meta.
