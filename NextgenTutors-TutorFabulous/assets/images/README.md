# Theme images (swappable)

Replace any image in two ways:

1. **Customizer** — Appearance → Customize → Motion & Media → Theme images  
   Paste a full URL from the WordPress Media Library.

2. **Files** — Drop a replacement JPG/PNG/WebP here using the exact filename:

| File | Used on |
|------|---------|
| `hero-bg.jpg` | Inner page heroes (about, contact, pricing, …) |
| `guarantee-bg.jpg` | Guarantee page hero |
| `about-feature.jpg` | About page feature photo |
| `become-tutor.jpg` | Become a Tutor visual |
| `cta-bg.jpg` | Parallax CTA bands (about, etc.) |
| `pricing-bg.jpg` | Pricing page CTA band |
| `home-video.jpg` | Kinetic homepage video tile poster |
| `hover-parent.jpg` | Image hover card — parent journey |
| `hover-tutor.jpg` | Image hover card — tutor journey |
| `hover-online.jpg` | Image hover card — online learning |

Customizer URL overrides local files. If both are empty, the theme falls back to legacy NextGen staging URLs.

Reference for motion CSS plugins: `style-add-ons-reference.png`
