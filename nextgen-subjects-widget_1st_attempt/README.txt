NextGen Subjects Widget
=======================

Install:
1. WordPress Admin > Plugins > Add New > Upload Plugin.
2. Upload nextgen-subjects-widget.zip.
3. Activate the plugin.
4. Use Appearance > Widgets > NextGen Subjects, or use the shortcode.

Shortcode example:
[nextgen_subjects subjects="Mathematics,English,Afrikaans,Physical Science,Life Sciences,Accounting,Geography,History,Computer Science"]

Widget subject format:
Subject|Description|icon

Only the subject name is required.
